## Full description

UpsellTrix helps merchants create spend-based free-gift promotions and tiered gift rewards for Online Store shoppers. Use it when you want shoppers to see how close they are to a free gift, then receive that gift when their cart spend reaches your threshold.

Set a spending threshold, choose a gift product, and show progress toward the reward. For multi-level offers, add tiers so additional gifts can unlock as cart spend grows.

Create and configure campaigns, save them as drafts, then activate or pause them when you are ready. Add UpsellTrix to your theme with the theme app embed so the progress experience can appear on supported product and cart paths.

When a shopper qualifies, eligible gift items can receive the free-gift discount so the reward is treated as free on supported cart checkout paths.

UpsellTrix is built for Shopify Online Store. Dawn is the primary verified theme experience. Enable the theme app embed on the theme you are testing. Draft and published themes are separate.

Need help? Email support@upselltrix.algorithmtrix.com.

## Key features

- Create Spend X → Free Gift campaigns with a spending threshold and a selected gift
- Configure tiered spending thresholds and corresponding gift rewards
- Show shoppers progress toward promotional rewards
- Draft, activate, and pause campaigns
- Add UpsellTrix through the Shopify theme app embed
- Apply free-gift pricing to eligible gift items
