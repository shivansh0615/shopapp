# UpsellTrix — App Icon & Feature Imagery Specs

Based on Shopify listing requirements / best practices (icon 1200×1200; screenshots 1600×900; clear UI-focused images; no logo-only feature images; no Shopify marks; no pricing in images).

---

## App icon

| Spec | Value |
|---|---|
| Size | **1200 × 1200 px** |
| Format | PNG or JPEG |
| Corners | Keep **square** (Shopify rounds) |
| Safe margin | Keep mark inset ~10–12% from edges |
| Content | Bold, simple mark; high contrast |
| Avoid | Tiny text, screenshots, Shopify trademarks, pricing, photoreal clutter |

### Brand direction

- Name: **UpsellTrix**  
- Do **not** put the full wordmark in the icon if it becomes unreadable at small sizes  
- Prefer a geometric “UT” monogram or abstract progress/threshold mark  
- Avoid purple-glow / generic AI gradients  

### Export checklist

- [ ] 1200×1200 master  
- [ ] Preview at 60×60 and 120×120 readability  
- [ ] No transparency issues on light/dark tiles  

---

## Feature media / banner

| Spec | Guidance |
|---|---|
| Role | Listing hero / feature media (not logo-only) |
| Composition | One focal point: real admin UI or storefront progress bar cropped into branded frame |
| Contrast | Strong contrast (≥ ~4.5:1 for text if any) |
| Text | Minimal; large if used; not a subtitle keyword dump |
| Avoid | Duplicate of app icon alone; Shopify logos; pricing; fake metrics |

Prefer a still from Shot 6 (storefront) or Shot 3 (builder) with subtle UpsellTrix brand treatment outside the UI chrome.

---

## Typography (listing imagery only)

- Use one clear sans for labels if needed  
- Max 1 short headline on feature media  
- No paragraph text inside screenshots  

---

## Export formats

- Icon: PNG (preferred) or JPEG  
- Screenshots: PNG 1600×900  
- Feature media: PNG or JPEG per Partner Dashboard accept list
